# 本地屏幕时间仪表盘

## 入口与运行

托盘第一项“打开仪表盘”调用 Windows 默认 URL 处理程序，打开 http://127.0.0.1:17643/ 。仪表盘服务与采集器同进程、自启，不额外运行 Node 服务。HTML、CSS、JavaScript 由 Go embed 打包，页面没有外部字体、CDN 或遥测。

页面遵循已选定的晴空蓝主题与粗线图形组件风格：蓝白底色、深蓝描边、偏移硬阴影和显著的回顾手柄。页面关闭时没有统计轮询；服务仅在请求时读取文件，同一天结果最多缓存 10 秒。

## 已实现功能

- 默认今天，可选择日期、前后翻日、回到今天。
- 有效使用、活跃操作、媒体播放、空闲四项指标。
- 全天、6 小时和 1 小时时间轴，支持拖动、点击、键盘左右移动一分钟、前后活动跳转及视野平移。
- 时间轴旁显示当时的进程、窗口标题、状态与活动时长。
- 选中时间之前最近 90 秒内的截图才可展示；不会跨越暂停、锁屏、休眠或空洞取图。快照注明拍摄时间与偏差，不表示连续录屏。
- 完整多显示器截图默认适应窗口，点击可切换原尺寸，并用滚动条平移。
- 应用排行、活跃与媒体组成、占比，点击筛选活动明细。
- 最近七天使用趋势，每天同时提示未采集时长，可点击进入单日。
- 明细支持应用、标题关键词、状态筛选、时间范围筛选以及分批显示。
- 查看今天时每 30 秒刷新；保留回顾位置和筛选。历史日期不重复加载日统计；状态连接仍定期检查。
- 采集器离线时保留页面已有结果并明确提示。

## 统计口径

所有仪表盘指标、排行、时间轴和明细由同一组不重叠区间生成。复用采集器 segmentKind 的空洞与状态规则。活跃操作和媒体播放计入有效使用；窗口进程无法识别时归入“未识别应用”，保证汇总守恒。

相邻记录间隔超过配置的 gap_report_sec 时，除明确休眠外均记为未采集；进程重新 start 前的间隔也记为未采集。历史最后一条记录没有后续观测时不推算至午夜。通过相邻日的最后/第一条记录切分跨午夜区间。

仅当天、状态更新时间在 35 秒内、状态 PID 属于当前进程、末条记录仍在空洞阈值内且未 stop 时，才把尾部延伸到现在。其他范围全部显式显示为未采集。人工暂停仅保留状态，区间不包含标题；休眠与未采集分开统计。

坏行和倒序时间戳计入数据质量提示。媒体播放沿用音频推断，界面不把它称为确定的观看行为。时间使用本机时区。

## 本地接口与访问边界

- GET /api/status：采集状态、更新时间、可用日期。
- GET /api/day?date=YYYY-MM-DD：区间、汇总、应用排行与截图索引。
- GET /shot/文件名：仅接受采集器时间命名的 PNG，拒绝任意路径与符号链接文件。
- 仅监听 127.0.0.1:17643，校验 Host、Origin 和跨站请求，不开放 CORS。
- 页面资源启用 CSP；窗口标题作为文本节点插入，不执行 HTML。
- 状态与截图响应不持久缓存。图片放大仅留在当前页面。

## 全屏回顾与拖动刷新

回顾区右上角“全屏回顾”通过浏览器 Fullscreen API 将截图、活动信息和时间轴一起展开；点击“退出全屏”或按 Esc 返回，保留回顾位置。请求被浏览器拒绝时显示具体原因。

拖动指针立即请求对应截图，不再等待停止拖动 100 毫秒。当前图加载后预读前后相邻图片，最多保留四张图片节点，回拖时直接复用节点，避免重复下载。过期请求不能覆盖新位置的画面，离开缓存的未完成请求会取消。窗口缺图、暂停、锁屏与休眠规则不变。
