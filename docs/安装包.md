# Windows 安装包

## 安装选项

- 两个版本：Windows x64（Intel/AMD 64 位）和 Windows ARM64；不包含 32 位 x86。
- 当前用户安装，无需管理员权限。默认程序位置：`%LOCALAPPDATA%\Programs\ScreenTimeObserver`。
- 数据位置独立选择，默认 `%LOCALAPPDATA%\ScreenTimeObserver\data`；截图、Wi-Fi 和日志均在所选数据目录内。
- 选择可写的本地磁盘目录。安装到需要管理员权限的目录不受当前用户安装模式支持。
- 默认启用登录后启动（HKCU Run），并可选择桌面快捷方式。
- 使用 Windows“已安装的应用”或开始菜单入口卸载；采集数据及配置保留。
- 升级安装保留原配置，不自动搬迁历史数据。不支持同时运行多个安装实例。
- 安装包没有代码签名，Windows 可能提示未知发布者。

## 构建

依赖 Go 1.26 和 Inno Setup 6.5.3。采集器及仪表盘不需要另外安装 Go、Node 或 Python。

```powershell
& D:\ScreenTimeObserver\installer\build.ps1
# 或指定编译器
& D:\ScreenTimeObserver\installer\build.ps1 -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

产物位于 `D:\ScreenTimeObserver\dist`。构建只打包新编译的程序和图标，不打包本机 config.json、截图、Wi-Fi、日志或历史数据；不覆盖根目录正在运行的采集器。

仅构建程序：`build.ps1 -BinariesOnly`，暂存于 `_probe\package\x64` 和 `_probe\package\arm64`。

## 命令行安装

可用 `/DIR="程序目录" /DATADIR="数据目录"` 指定位置，`/TASKS="autostart,desktopicon"` 选择任务。
静默安装支持 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`；静默安装不会立即启动采集器。
安装日志使用 `/LOG="完整日志路径"` 保存。
